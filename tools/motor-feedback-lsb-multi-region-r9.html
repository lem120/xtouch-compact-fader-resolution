X-Touch Compact Multi-Region Same-MSB Boundary Test R9

Tests whether the R5/R8 112/113 boundary repeats at several MSB regions across the fader travel.

Non-firmware / non-destructive. Sends only ordinary MIDI Pitch Bend messages. No SysEx, preset write or flash access. Close Ableton Live, X-TOUCH Editor and other MIDI apps. Put the Compact in Mackie Control mode. Do not touch the tested fader during the sequence.

Purpose

R5 and R8 isolated an exact same-MSB boundary around MSB 100:

12912 = LSB 112 / MSB 100 → lower motor state
12913 = LSB 113 / MSB 100 → upper motor state

R9 repeats the same adjacent-count test at multiple MSB regions. If the 112/113 boundary repeats, that supports a regular target-conversion/quantization rule. If it shifts with position, calibration or nonlinear motor mapping becomes more likely.
