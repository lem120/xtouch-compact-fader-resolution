X-Touch Compact Motor Feedback LSB Hold Test R3

Forced-hold mapper for the host → motor Pitch Bend path.

Non-firmware / non-destructive. This page sends only ordinary MIDI Pitch Bend messages. It does not send SysEx, enter update mode, change presets or write flash. Close Ableton Live, X-TOUCH Editor and other MIDI apps. Put the Compact in Mackie Control mode. Do not touch the tested fader during a sequence.

1. Connect

Tested fader:

R3 differs from R2: every target is retransmitted at 20 Hz for a fixed hold period. Each LSB target is tested from the same 12800 baseline. This removes the cumulative staircase ambiguity seen in R2.

2. Resolution tests

Test D — Short forced-hold map

Warm-up, then tests offsets +16, +32, +64, +96, +127. MSB remains 100 for every target. Each target is bracketed by a repeated 12800 baseline.

Test E — Full forced-hold map

Warm-up, then tests offsets +8, +16, +24, +32, +48, +64, +80, +96, +112, +127. Each phase is sent continuously at 20 Hz.

Manual target
LSB offset from 12800:

For any offset 0–127, the target remains inside MSB 100: raw = 12800 + offset.
