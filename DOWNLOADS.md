# Downloads

**Status: public Compact firmware download is being prepared. No installable firmware release is currently published here.**

The plan is to make the Compact firmware offering available free of charge. Free download does not by itself define source-code availability or a redistribution licence; those terms will accompany the actual release.

## Where downloads will appear

Use the repository's [GitHub Releases page](https://github.com/lem120/xtouch-compact-fader-resolution/releases) once a release is published. Each release entry should identify the supported Compact configuration and its exact assets. Until then, this page is the status reference.

**Code → Download ZIP is the research/documentation repository, not a firmware update package.**

## Planned package

- A precisely identified firmware patch or other finalized distribution format, with version and SHA-256 checksums.
- The supported Standard Mode profile and a description of standalone versus host-owned behavior.
- A matching driver/reference integration when required for the advertised features.
- Installation instructions for the updater environment actually validated.
- Backup, rollback and supported recovery instructions.
- Release notes, tested hardware/software combinations and known limitations.

The existing preferred model is to apply a patch locally to an identified original image obtained from the user's X-TOUCH Editor installation. This documentation update does not publish vendor or modified firmware images and does not finalize the delivery format.

## What firmware alone does not include

A console UI, plugin licensing, automatic Ableton mapping and bank contents are host/application features. The future download will state which controls work without a host and which require the supplied integration. Compatibility with arbitrary DAWs or third-party mappings is not promised.

CONSOLE 4000 E Remote will have separate presentation and distribution. Its plugin package is not the firmware download.
