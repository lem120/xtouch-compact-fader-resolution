# MIDI captures

This directory contains short representative excerpts used by the article.

Included:

- `compact-mc-sample.txt` — X-Touch Compact, firmware 1.14, Mackie Control sample showing ordinary `LSB=0` behavior around unity.
- `xtouch-one-control-test.txt` — X-Touch One control sample using the same decoding path, showing active LSB values.

Future full captures should include:

- controller model;
- firmware version shown by the editor/device;
- mode (Standard or MC);
- host software state;
- capture tool version;
- test gesture (for example, slow sweep around unity).

Keep public captures focused and free of unrelated system information.
